# JavaScript Events Practice Journey ⚡

Welcome to my **JavaScript Events** repository! This repository serves as a structured digital log where I document my hands-on experiments, event-driven mini-demos, styling interactions, and input validations while learning how events work in JavaScript.

## 📂 Repository Structure & File Overview

## 🛠️ What I Am Learning & Practicing

Through building these files, I am strengthening my understanding of:
* Handling user-triggered browser events such as `onclick`, `onmouseover`, and `onmouseout`.
* Updating UI elements dynamically—including backgrounds, text colours, and image borders—in response to events.
* Reading user input from fields and validating emails, numbers, forms, and password confirmations.
* Organizing external stylesheets (`index.css`), scripts (`index.js`), and image assets (`Lotus.jpg`, `girl.jpg`) alongside HTML event demos.
